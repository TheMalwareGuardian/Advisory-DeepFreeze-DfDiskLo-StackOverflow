# ***📦 Software Packages***

This folder contains the original Deep Freeze installation packages used during the vulnerability research and verification process.

| File               | Description |
|--------------------|-------------|
| [`Faronics_DFS.zip`](https://www.faronics.com/es/downloads_es/download-files_es?product=DFS) | Deep Freeze **Standard** edition installer |
| [`Faronics_DFE.zip`](https://www.faronics.com/es/downloads_es/download-files_es?product=DFE) | Deep Freeze **Enterprise Workstation** edition installer |

The drivers extracted from both packages were analyzed independently in order to verify the presence of the vulnerability across different product editions and versions.
